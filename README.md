Chicory is a UCI-compatible, dependence-less chess engine built in Rust 

## Getting Started

Pre-built release version of Chicory, for Linux, Mac, and Windows, can be found [here](https://github.com/achester88/chicory-engine/releases)

### From Scratch

Step 1: Clone repo

```bash
git clone https://github.com/achester88/chicory-engine
```

```bash
cd chicory-engine
```

Step 2: Build via Cargo

```bash
cargo build --release
```

Step 3: Find Release at 

```bash
./target/release/chicory
```
